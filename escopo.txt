Projeto
Go API – Gestão de Projetos e Tarefas (Trello-like)

Uma aplicação web para gestão de projetos, quadros, listas e tarefas, com autenticação, permissões, drag-and-drop e dashboard.

🧠 O que ESSE projeto prova no seu portfólio

✔ Go backend bem arquitetado
✔ API REST profissional
✔ Auth JWT + RBAC
✔ Relacionamentos complexos no banco
✔ Frontend SPA moderno (Vue 3)
✔ Integração real backend ↔ frontend
✔ Docker + CI/CD
✔ Pronto para produção

👉 Esse tipo de projeto passa em entrevista fácil.
